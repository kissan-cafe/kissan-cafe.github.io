AIニュース朝7時 アップローダー

このアプリについて

「AIニュース朝7時」は、AIのふたり（そら・たけ）が国内ビジネスと世界のAIのニュースを話す、毎朝7時公開の5分番組です。台本・音声・映像はAIで作り、AIが作った番組であることを動画の中と説明欄で伝えています。

「AIニュース朝7時 アップローダー」は、できあがった動画を運営者自身のYouTubeチャンネルにだけアップロードするための内部ツールです。一般の利用者がログインして使うものではありません。

使うYouTubeの機能

  • YouTube Data API v3 の動画のアップロード（videos.insert）
  • 題名・説明・タグ・公開予約の設定、サムネイルの設定、再生リストへの追加

ほかの人のチャンネルや個人の情報を読み取ったり、保存したりすることはありません。

About (English)

"AI News Asa 7" is a five-minute daily news show published at 7:00 JST, created with AI and clearly disclosed as AI-generated. "AI News Asa 7 Uploader" is an internal tool that uploads each finished episode only to the operator's own YouTube channel via the YouTube Data API (videos.insert, thumbnails, playlists, scheduled publishing). It is not offered to the public and does not access any other user's data.
