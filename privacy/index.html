PRIVACY POLICY

プライバシーポリシー

この方針は、「きっさんの独り言」（以下「運営者」）が提供する「AIニュース朝7時 アップローダー」（以下「本アプリ」）での情報の扱いを定めるものです。最終更新日：2026年11月24日

1. 本アプリが使う情報

本アプリは、運営者自身のYouTubeチャンネルに動画をアップロードするため、Googleの認証（OAuth 2.0）で運営者自身のアカウントから「YouTubeへの動画のアップロード」の許可を受けます。本アプリが扱うのは、その許可を表す認証情報（アクセストークン・リフレッシュトークン）と、運営者が作った動画・題名・説明・サムネイルだけです。

2. 使い道

認証情報は、運営者のチャンネルへ動画をアップロードし、公開の予約や再生リストへの追加を行うためだけに使います。広告、分析、販売、ほかのサービスへの提供には使いません。

3. 第三者への提供

運営者は、本アプリで扱う情報を第三者に売ったり、渡したりしません。

4. 保存と管理

リフレッシュトークンなどの認証情報は、暗号化された保管場所（GitHubのシークレット）に置き、アップロードの処理の中でだけ読み出します。認証情報は運営者のチャンネルにだけ使われます。

5. 許可の取り消し

本アプリへの許可は、Googleアカウントの「サードパーティのアプリとサービス」からいつでも取り消せます。取り消すと、本アプリはアップロードできなくなります。

6. YouTube API サービスについて

本アプリは YouTube API サービスを使っています。YouTubeの利用には YouTube 利用規約 が、Googleでの情報の扱いには Google プライバシーポリシー が適用されます。

7. 一般の利用者について

本アプリは運営者だけが使う内部ツールで、一般の利用者がログインすることはありません。番組を見る人の個人情報を、本アプリが集めることはありません。

8. お問い合わせ

この方針についてのお問い合わせは、Googleの同意画面に表示されるサポート用メールアドレスまでお寄せください。

9. 改定

この方針を変えるときは、このページで最終更新日とともにお知らせします。

English summary

"AI News Asa 7 Uploader" is an internal tool used only by the operator to upload videos to the operator's own YouTube channel. It requests only the YouTube upload permission via Google OAuth, stores the resulting tokens encrypted in GitHub Secrets, uses them solely to upload and schedule the operator's videos, and never sells or shares any data. You can revoke access at any time at https://myaccount.google.com/permissions. This app uses YouTube API Services; see the YouTube Terms of Service (https://www.youtube.com/t/terms) and the Google Privacy Policy (https://policies.google.com/privacy).
